# 胡言乱语值与成就系统

## 用户与目标

面向在手机端反复生成短句的 Toy 用户。系统用一个可理解、可积累的数字给生成行为即时反馈，同时不把复制、登录或评分等动作包装成可刷分任务。

## 规则

- 每次成功得到有效结果，胡言乱语值 `+1`；失败、拦截与取消不计分。
- 值保存到 Toy JS SDK 云存储键 `nonsense-value-v1`，本地仅作快速缓存。
- 老用户首次加载时，以现有累计生成数作为最低迁移值，不会从零开始。
- 胡言乱语值就是排行榜的唯一分数；排行榜、个人页与成就读取同一个值。

## 成就阶梯

| 门槛 | 勋章 | 成就文案 | 视觉符号 |
| ---: | --- | --- | --- |
| 1 | 初次失真 | 现实第一次被你说得有点不对劲。 | 出现故障切口的对话气泡 |
| 5 | 逻辑松动 | 你的因果关系开始学会自由活动。 | 从规则网格中松脱的螺栓 |
| 20 | 语义漂移 | 句子还在原地，意思已经出发。 | 漂离标点航线的纸船气泡 |
| 50 | 语言实验员 | 获准在常识边缘进行小规模试验。 | 盛放标点的实验烧瓶 |
| 100 | 现实改写者 | 现实递交了修订意见，你选择全部拒收。 | 改写世界页面的红色铅笔 |
| 300 | 终身胡言 | 无需证明什么，语言已经开始证明你。 | 戴冠的莫比乌斯语言带 |

## 流程与状态

1. 生成成功后先展示结果，再把同一个新值异步写入本地缓存、Toy KV 和排行榜。
2. 若本次跨过门槛，页面底部显示一条可被读屏读取的解锁提示；不会打断生成。
3. 「我的」页展示当前值、当前勋章、距离下一等级的进度以及全部六枚勋章。
4. 未登录或 SDK 不可用时继续本地累计，并提示登录后同步；云端读取失败不会阻塞生成。
5. 已满级时进度固定为 100%，文案改为“全部成就已获得”。

## 组件与无障碍

- `AchievementSummary`：当前勋章、当前值、下一门槛和进度条；进度条提供 `aria-valuenow`、`aria-valuemin`、`aria-valuemax`。
- `AchievementGrid`：两列勋章卡片；未解锁项降低饱和度和透明度，但仍显示要求与文案，信息不只依赖颜色。
- `AchievementToast`：`role="status"`、`aria-live="polite"`，4.2 秒后自动消失；减少动态效果偏好下禁用位移动画。
- 移动端维持两列，320px 以下降为一列；触控目标不承担隐藏操作。

实现目标为现有 React + Vite Toy，不新增服务端接口或第三方依赖。
