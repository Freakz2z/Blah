# 网络语境层

`shared/generate/trending.ts` 不是关键词大全，而是生成质量系统的一部分。它只在某个网络表达能帮助当前输入形成更具体的歪理时，向模型提供最多两条可选语境。

## 不可破坏的原则

1. **相关性优先**：没有明确语义信号就返回空列表，不用热梗通常比硬塞更好。
2. **事实骨架优先**：梗只能提供解释角度，不能替换输入中的人物、动作、否定、转折或情绪方向。
3. **严肃语境关闭**：真实伤害、死亡、急救、事故、灾难、失踪等输入默认不注入网络语境。
4. **不过期**：当前项有生效区间和复核日期；过期后运行时自动失效，超过 45 天未复核则测试失败。
5. **不奖励露梗**：候选评分不因包含热词直接加分，最终仍由切题、保真、具体性和句子质量决定。
6. **可追溯**：当前梗记录公开来源和最后复核日期，但来源信息不会进入模型提示词。

## 内容分层

- `current`：正在传播的网络梗，必须有 `activeFrom`、`activeUntil`、`reviewedAt` 和来源。
- `evergreen`：已经稳定进入日常表达的网络语境，不假装是实时热点，但仍需精确匹配输入。
- `seasonal`：只在指定的上海时区月日窗口内生效，例如三伏天和开学季。
- `archive`：保留审计记录但永不注入，用于证明过期项不会因旧关键词重新出现。

## 选择流程

1. 将日期转换为 `Asia/Shanghai`，过滤未开始、已结束、非当季和归档项。
2. 若输入属于严肃语境且没有明确提到某个有效梗，直接返回空列表。
3. 根据每项的加权 `signals` 计算相关性；命中 `avoidSignals` 立即淘汰。
4. 按相关性、编辑优先级和稳定哈希排序；同一 `family` 只保留一项。
5. 最多返回两项，提示词要求模型最多使用其中一个。

## 编辑维护

每次复核当前项时：

1. 通过 B站原始内容、平台盘点或可信媒体确认传播语境。
2. 写清它适合什么输入，也必须写清容易误伤的输入。
3. 将提示压缩为模型不依赖旧知识也能正确使用的一句话。
4. 更新 `reviewedAt` 和生效区间；不再活跃的项目改为 `archive`，不要伪装成常青表达。
5. 扩充 `tests/trending-relevance.test.mjs` 的正例、字面碰撞反例和严肃语境反例。
6. 运行 `npm test`。若当前项不足三个、已经过期或超过 45 天未复核，测试必须失败。

部署 Worker 后运行 `npm run eval:live`，会从 `api.freakz2z.com` 调用真实模型，覆盖三种模式、三档长度、相关热梗、无关输入和严肃语境，并把逐条结果保存到 `tmp/live-eval/`。该评测不属于普通单元测试，避免在 CI 中意外消耗模型调用。

自动抓取热搜不能直接进入生成提示词：热搜不是梗，且可能包含政治、灾难、攻击性内容或只有标题没有共享语境。自动化可以用于发现候选，但进入库前必须人工审校。
