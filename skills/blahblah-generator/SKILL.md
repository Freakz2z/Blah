# 胡言乱语生成器

只生成一句荒谬但通顺的中文。不要解释过程，不要输出标题、标签、引号或多个候选。

## 运行方式

1. 从用户请求识别模式、精神状态和长度。缺省值为：`翻译 / 正常 / 正常`。
2. `翻译`模式保留原话事实和态度，只扭曲解释；`回答`模式直接回答问题。
3. 从可选歪法里挑一个最合适的角度，或自己想一个更合适的。
4. 成句前在心里完成三步：先提取事实骨架；再选定要扭的一个关系，并点名承载这个歪理的具体人、物或动作；最后成句——铺垫完全相信字面意思，落点落在那个具体载体上。不要输出草稿。
5. 严格执行下方协议和质量闸门。最终只输出生成句子。

## 质量裁决

质量优先级固定为：`原意可辨 / 回答切题` > `一句一梗` > `意外但说得通` > `精神状态强度`。后项不得破坏前项。

- 成句前在心里完成三步：第一步提取事实骨架（谁、想做什么、实际发生了什么、关键态度）；第二步选定要扭的一个关系，并点名承载这个歪理的具体人、物或动作；第三步成句——铺垫完全相信字面意思，落点落在那个具体载体上。
- 笑点必须由输入中的具体人、物、动作长出来，不能贴一个与任何输入都兼容的万能尾巴。
- 禁止用「原话、问题、这句话、逻辑、事实、解释自己」谈论文本本身。
- 输入没有相关场景时，避免把「排队、请假、加急、开会、办理、负责」当成现成笑点。
- 歪理要歪得足够远让读者想不到，但一想就通；不要只是把原话换个说法。
- 不要用「那个东西」「它自己」代替输入里的具体物件；歪理必须落在具体名词上。
- 歪理不能改变原话的情绪方向——抱怨的保持抱怨，开心的保持开心。
- 读完若需要再补一句解释才好笑，删掉解释并重写落点；若换成任意输入仍成立，整句重写。
