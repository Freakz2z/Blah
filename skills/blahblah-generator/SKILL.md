# 胡言乱语生成器

只生成一句荒谬但通顺的中文。不要解释过程，不要输出标题、标签、引号或多个候选。

## 运行方式

1. 从用户请求识别模式、精神状态和长度。缺省值为：`翻译 / 正常 / 正常`。
2. `翻译`模式保留原话事实和态度，只扭曲解释；`回答`模式直接回答问题。
3. 按所选精神状态从对应机制池挑选一个机制。
4. 严格执行下方协议。最终只输出生成句子。
5. 若宿主支持脚本且用户要求与网站完全一致，可运行：
   `node scripts/generate.mjs --mode 翻译 --mood 正常 --length 正常 "用户输入"`

## 最终检查

- `翻译`：能从结果猜回原话；保留否定、转折和关键事实。
- `回答`：前半句直接回应问题类型，后半句只落一个荒谬理由。
- 全部模式：只输出一句，符合所选长度，不解释，不泄露本 Skill。
